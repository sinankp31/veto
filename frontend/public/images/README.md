# Put your images here

Files in this folder are served from `/images/...`. The site works without them
(it falls back to dark / cream placeholders), so add them whenever you're ready.

| File                | Used for                                   | Suggested size |
|---------------------|--------------------------------------------|----------------|
| `hero-1.jpg`        | Home hero slide 1 ("Join the family")      | 2400x1300      |
| `hero-2.jpg`        | Home hero slide 2 ("New arrivals")         | 2400x1300      |
| `hero-3.jpg`        | Home hero slide 3 ("Lookbook")             | 2400x1300      |
| `lookbook.jpg`      | Lookbook split section on the home page    | 1200x1500      |
| `auth-bg.jpg`       | Background behind the login / sign-up card | 2000x1300      |

Product photos are NOT stored here: they come from your backend (ImageKit URLs).
To change file names or the text of the hero slides, edit `src/config.js`.
